## 我们希望做什么

让喜欢韩国综艺《The Community》（더 커뮤니티）的人，可以在一个**中文优先**、便于分享的网站里体验两季的价值观测试、看懂每个维度。测试后立即看到**与自己最相近的几位节目嘉宾**，以及他们经过核实的主要公开社交平台和账号链接。用户在**自己选择保存**后，还能跨设备找回自己的结果。将来有余力，再尝试多人参与的资源交易、协商和社交策略小游戏。

优先级：**中文第二季测试与嘉宾匹配 → 中文第一季测试与嘉宾匹配 → 用户自己的历史结果 → 多人游戏**。登录可以作为保存结果的入口，不应成为参加测试或查看嘉宾匹配的强制条件。

## 与现有网站的差异

1. **先韩文原文、后信达雅的中文译文：** 题干和选项都能中韩逐项核对；准确性、翻译版本、来源和合法转载权限都有准入标准。没有权限的节目原题不会假装已经复刻。
2. **将来测完马上匹配嘉宾：** 已实现带证据门槛的同季相似度算法和合成数据测试；真实嘉宾分数尚未核验，网站暂不生成任何嘉宾排名。
3. **找到嘉宾在哪里活跃：** 公开来源中的社媒账号链接目录已上线；账号本人身份和当前控制权仍待人工确认。只有具备近期、可比活动证据才称为「最活跃」，不会根据粉丝数推断。

匹配方法、社媒资料证据和验收标准见 [嘉宾匹配设计](docs/GUEST-MATCHING.md)。

题库的原文校对、忠实翻译和复核标准见 [翻译与题库标准](docs/TRANSLATION-STANDARD.md)。题目**是否齐全**、所有答题路径和最终结论是否正确，参见 [题库、路径和评分验证矩阵](docs/VERIFICATION-MATRIX.md)：它把原创演示版的自动测试与尚无可靠证据的官方复刻分开。

当前已定位两季公开客户端的 **87＋37＝124 个源题标识**，逐题记录选项数量、所属组、客户端反向标志、来源资源指纹及译文／独立审校缺口，见 [纯元数据索引](data/original-question-index.json)。索引不含原题正文。用户报告已获当前公开材料的非营利翻译许可；授权原件尚未由项目独立核验。新试填页从同一份已公开的源题／AI 草稿构建，不另建一份易漂移的题库。原题试填完成也不能视为正式译文、全部原版路径或官方计分复刻完成。

项目的完整愿望与验收标准见 [WISH.md](WISH.md)。

## 技术方案

- 界面：采用 **Astro + Tailwind CSS 4**，保留零登录要求的前端问卷逻辑；当前版本已具备正式生产部署与桌面／440×956 CSS px 浏览器验收记录，发布版本可与 [GitHub 精确 SHA](docs/DEPLOYMENT.md) 核对。
- 登录：可选 GitHub OAuth。访客无需登录即可体验；愿意长期保存才需要账号。
- 结果：计划用 Supabase Auth + 私有 Postgres 表，配合行级权限（RLS）隔离每位用户。
- 隐私：默认只在本地浏览器保留临时结果；明确同意后才上传。提供本人查看、下载和删除。
- 费用：当前公开静态站由 GitHub Pages 与标准 GitHub-hosted Actions runner 发布；Vercel Hobby 仅作历史回退站，未来的可选私有后端需另行核价和验收；不擅自开通付费服务。

**静态托管迁移（2026-10-30，已发布）：** [PR #50](https://github.com/mykcs/the-community-lab/pull/50) 合并后，`main` 提交 `7cbb659c5d16c6002767ee32a0bd062d516badbf` 的 [Pages 构建与发布](https://github.com/mykcs/the-community-lab/actions/runs/41028239651) 均成功。正式首页和独立译审页均返回 HTTP 200，主站 JS/CSS 也返回 200；实际浏览器走通了第二季 6 题、第一季 8 题、暂停续答和结果卡。440×956 CSS px 手机视口无横向溢出；它是浏览器模拟而非实体手机。Vercel Git 自动部署按官方 `git.deploymentEnabled=false` 关闭，保留旧生产快照用于回退。GitHub Pages 免费托管公开仓库、公共标准 runner 的构建不扣计费计算额度，但有 1 GB 站点大小、约 100 GB/月软流量限制，不是无限资源。Pages 只提供静态文件；PR #11 的可选登录／私人历史记录仍未上线，不能直接迁入 Pages 当作有后端。发布切换及回退规则见 [部署证据](docs/DEPLOYMENT.md)。

具体架构、预算与隐私门槛见 [设计方案](docs/ARCHITECTURE.md)。

## 不做的事

- 不在公开仓库存放开发者或参与者的私人信息、实际答卷、邮箱、密码、OAuth Secret 或数据库密钥。
- 未确认许可前，不批量复制节目原题、商标、海报、画面、音乐或题库数据。
- 不将娱乐性的价值观结果宣传为经过验证的心理学诊断，也不公开展示某位用户的政治倾向。
- 未经明确批准，不自动购买域名、升级付费套餐或发起高成本服务。

项目约束见 [AGENTS.md](AGENTS.md)。目前欢迎先通过 Issue 提交**公开来源**、许可证信息或玩法建议，请勿提交真实用户答卷。
