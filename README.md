# The Community Lab · 非官方《The Community》测试与游戏实验室

> 独立粉丝研究项目，**不是**节目方、Wavve 或测试制作团队的官方网站，也未获得其背书。
>
 当前状态：**项目立项与资料调查完成；测试、登录、数据库、游戏均尚未上线。**

## 我们希望做什么

让喜欢韩国综艺《The Community》（더 커뮤니티）的人，可以在一个便于分享的网站里体验两季的价值观测试、看懂每个维度，并在**自己选择保存**后，跨设备找回自己的结果。将来有余力，再尝试多人参与的资源交易、协商和社交策略小游戏。

优先级：**第二季测试 → 第一季测试 → 用户自己的历史结果 → 多人游戏**。登录可以作为保存结果的入口，不应成为参加测试的强制条件。

项目的完整愿望与验收标准见 [WISH.md](WISH.md)。

## 技术方案

- 界面：Next.js + TypeScript；在 Vercel 部署，优先兼顾桌面和手机。
- 登录：可选 GitHub OAuth。访客无需登录即可体验；愿意长期保存才需要账号。
- 结果：计划用 Supabase Auth + 私有 Postgres 表，配合行级权限（RLS）隔离每位用户。
- 隐私：默认只在本地浏览器保留临时结果；明确同意后才上传。提供本人查看、下载和删除。
- 费用：初期以 GitHub、Vercel Hobby、Supabase Free 的**免费额度**为目标；不擅自开通付费服务。

具体架构、预算与隐私门槛见 [设计方案](docs/ARCHITECTURE.md)。

## 我们先复用哪些成熟成果

1. [第二季现有测试网站](https://thecommunity.co.kr/)：优先参考官方已公开的体验与结果概念。
2. [第一季历史测试页面](https://the-community-survey.web.app/)：调查是否仍可访问、能否合法引用；不能默认复制题库。
3. [8values 开源项目](https://github.com/8values/8values.github.io)：MIT 许可证，适合学习“问卷 → 维度计分 → 结果可视化”的通用实现；**不是**《The Community》原版。
4. [非官方第一、二季人物倾向对照页面](https://thecommunity-fan.pages.dev/)：可参考信息组织方式，不能据此断言题库或源码开放。

## 不做的事

- 不在公开仓库存放开发者或参与者的私人信息、实际答卷、邮箱、密码、OAuth Secret 或数据库密钥。
- 未确认许可前，不批量复制节目原题、商标、海报、画面、音乐或题库数据。
- 不将娱乐性的价值观结果宣传为经过验证的心理学诊断，也不公开展示某位用户的政治倾向。
- 未经明确批准，不自动购买域名、升级付费套餐或发起高成本服务。
