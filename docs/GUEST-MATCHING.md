# 核心特色设计 · 中文结果、嘉宾相似度与社交媒体导航

状态：**算法及合成数据测试已实现；没有符合条件的真实嘉宾分数，网站不显示真实嘉宾匹配**。记录日期：2026-10-29。

2026-10-29 准入范围补充：经用户明确授权，网站可展示仅用于导航的公开社媒链接目录；每条链接须有两名独立 Agent 对本人公开原始来源的逐条核查记录。该例外不代表真人人工复核、法律身份认证或近期活跃度核实；Instagram 页面未直接读取时须如实说明。目录不得进入匹配、分数、排名或活跃度判断。嘉宾分数与身份资料仍须满足本文件原有人工验证要求后才可入库。

## 用户最终看到什么

1. 网站所有主要文案均为中文；嘉宾使用节目中公开昵称，韩文名可作为括号内对照。
2. 完成某一季测试后立即显示「你最接近的嘉宾」3–5 张卡片，并列出嘉宾和用户在该季每个维度的差异。
3. 每张卡片给出真实可点击的公开社媒主页（X／原 Twitter、Instagram、YouTube 等）。能验证近期活跃度时标「主要活跃于」，否则仅列「已核实的公开账号」。
4. 卡片附节目结果来源和社媒身份核实时间；不展示未经证实的嘉宾分数、私人身份或账号。
5. 访客可直接使用，无需登录；计算默认在浏览器完成，不将访客政治观点传给嘉宾、社媒平台或服务器。

## 先复用已有成果

已有[韩国粉丝第一／二季嘉宾倾向对照网站](https://thecommunity-fan.pages.dev/)，作者在 [2026-09-08 社区帖子](https://gall.dcinside.com/mgallery/board/view/?id=community2&no=4171) 介绍了按嘉宾、队伍比较和相似程度可视化。网站的公开描述还提到第二季 `−2、−1、+1、+2` 四档之间采用相邻档距离 1 的比较规则。

这说明 **嘉宾相似性可视化已有先例**。本项目真正的增量是：中文解释、用户个人答卷自动与嘉宾匹配、明确来源证据，以及嘉宾本人活跃社媒导航。未确认对方源码许可证时，研究公开方法，但不直接复制代码、图库或数据集。

## 匹配算法的证据门槛

- **按季分别比较**：第一季四个领域、第二季三个价值轴，数据不同不得混合；用户和嘉宾必须使用可比较的同一题库／评分版本。
- **只用已核实数值**：不能从嘉宾的分类字母或截图颜色臆测精确连续分数。如果只有类别，最多展示「类别相同／相近」，不得伪装为小数分值排名。
- **透明排序**：所有嘉宾数值完整且同尺度时，可把每维度归一化到共同范围，计算每维距离并取均值；排名按照差异从小到大，显示并列与各轴差距。独立原创版本的分数不得与官方嘉宾结果强行比较。
- **准确措辞**：以「节目测试中选择倾向相近」说明结果；不等于现实政治观点、人格、友谊或价值判断相同。是否显示百分比必须取决于可证实的计分解释，不能凭公式自行制造“准确率”。
- **缺失数据**：缺一项或来源不可核验的嘉宾不进入精确榜；展示「资料待核实」，不能以 0 代替缺失值。

## 社交账号信息质量

建议公开数据记录字段：

| 字段 | 要求 |
| --- | --- |
| `stage_name` / `season` | 节目公开昵称及季别，不存私人姓名或隐私信息 |
| `platform` / `profile_url` | 平台标准名称和可访问的公开主页地址；Twitter 与 X 是同一平台 |
| `identity_source_url` | 本人简介的交叉链接、节目方正式介绍或等效的公开归属证据 |
| `verified_at` | 最后一次验证账号归属的日期 |
| `activity_window` / `activity_checked_at` | 判定活跃的窗口及核验日期；无证据则留空 |
| `activity_status` | `verified-active`、`known-account`、`unknown`；只有可比较的公开发帖活动才能称某平台最活跃 |

「最活跃」的暂定可解释规则：在同样最近 30 天或 90 天的窗口内，比较可公开核实的原创发布数量，注明是否包含视频／直播，公开数据覆盖不足时不排名。**粉丝数多不代表最近活跃。** 绝不编造账号、猜测别名，亦不绕过登录墙或平台采集限制。

## 2026-10-29 证据完整性负例（仅算法，不代表真实数据已核实）

- **避免一个人上榜两次**：同一季出现相同嘉宾 ID 的两份记录，即使分数不同也全部排除，直到人工去重并确立唯一权威记录；不会拿其中一份碰运气。已有单元测试覆盖。
- **证据日期不能只匹配字符串**：例如 `2026-02-30`、`2026-13-01` 和未来日期均不能作为已核验日期。真实日期须在观察当天或之前。
- **平台账号需与地址对应**：声称是 X 的账号不能指向非 X 域名；Instagram、YouTube 同理。不能把帖子、视频、分享页面冒充本人主页；用户名密码嵌入链接、localhost/局域地址也不能作为公开出处。
- **程序通过不等于人工认证**：嘉宾分数及用于匹配的身份资料，仍必须由人工审校者打开来源、确认归属及评分来源并记录核查日期后才能入库。唯一例外是经过用户明确授权的社媒导航目录：允许在两名独立 Agent 逐条核查公开原始来源后展示链接，但必须标明其为 Agent 核查、尚未经真人逐条复核；这类导航记录永不作为匹配或身份认证证据。现阶段没有符合条件的真实嘉宾成绩，不上线排名。

此项是独立于第一季／第二季演示题库的防错完善；不要据此改写「同季嘉宾已验证」的状态。
