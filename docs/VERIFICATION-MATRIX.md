## 四层验证，必须逐层过门

### L1 · 内容完整性：全部题目到底有没有

1. 对每一季建立**有编号的权威来源清单**；逐题记录韩文题干、全部韩文选项、选项数量、答题类型、原站顺序、截图/网页位置、抓取核实日期、重用权限与源版本。
2. 只在合法许可下保存、公开原题；权限不明时只记录题号、题型、元数据和出处链接。禁止用模型脑补补齐缺失题目。
3. 交叉核对题数、题号是否连续或明示的非连续编号、重复、缺项、隐藏条件题、原版是否更新。公开页面数量一致**只是必要条件，不是充分条件**。
4. 每道发布题强制「韩文原文在前、中文译文在后」，题干、所有选项和量表都需独立双语审校；否定、条件、程度词与计分极性不能漂移。复核详见 [翻译标准](TRANSLATION-STANDARD.md)。

**验收输出**：两季各一份逐题证据清单和来源许可状态，覆盖率=通过审核的原题数/实际原题数。当前两季均为 **0/未知可合法转载原题**，不能用演示题 8/87 或 6/37 表示已复刻百分比。

### L2 · 路径完整性：每个选择会把人带到哪

1. 把原站问卷建模为**有向状态图**：起点、题节点、每个可选答案的转移、返回/修改答案、条件跳题、完成节点、取消或重新开始。
2. 如果官方题数是固定的，也需检查是否存在根据先前答案改变顺序、隐藏题目或提前结束的分支，不能未经验证就假定是线性排列。
3. 为每条边留一个真实原站观察或可靠原始资料的证据；对所有可达节点做图遍历，检测死路、无法到达的题、循环与提前提交。
4. 使用模拟用户或可许可的离线样本做路径覆盖；有指数级选项组合时，先用图覆盖+边界/成对覆盖，再用精确的程序化穷举测试本站的小型演示集。

**验收输出**：原站可达图、每条边的证据以及本网站对应路径的差异清单。当前公开客户端可观察到固定季别 seed 排列、顺序前进／回退及最终服务端提交；完整原站浏览器状态图和各边验收仍为 **UNKNOWN**。

### L3 · 结果正确性：答案如何变成分数、标签

1. 拆解每题权重、反向题、缺失答案处理、每轴归一化、阈值/分档、并列处理、最终人物或倾向标签的判定；没有来源就不设为「官方算法」。
2. 收集**经许可且同版本**的原站输入→输出金标准样例；至少有每个维度的两端、恰好在阈值上下、逆向题、平分/并列、重测时结果不变。与本站同输入差分测试并附可复现报告。
3. 对本站原创评分做性质测试：输入完整性检查、选项极性、单维度独立性、前后重复一致性、未答题不计分；小题库做全组合穷举。
4. 保留 **题库版本 + 评分版本 + 译文版本**，旧用户结果不能因升级算法静默改变。

**验收输出**：来源、可运行金标准、同输入的差异/误差、每轴与最终标签的验收记录。当前**演示版的内部一致性可测**，但原站差分测试**不可开展**。

### L4 · 真实产品：嘉宾匹配、账号和隐私

1. 只纳入可追溯的同季、同评分版本、同维度嘉宾结果，缺失值不得用虚构分数填补；测试排序、并列、不同季隔离。
2. 社交账号必须经公开来源归属核查；「最活跃」还须有跨平台可比的近期活动证据，否则仅显示「已验证公开账号」。
3. GitHub OAuth 只用于识别登录用户，写入个人结果必须明确同意、服务端隔离、可导出/删除；双账号交叉访问与删后读回均验收。
4. 访问者能在不登录的情况下完成测验，默认只在本机计算；网站清楚标注「独立非官方」。

## 自动测试与人为审计的分工

- 运行 `npm test`：本站原创小型题库的题目数据、两季计分与嘉宾匹配单元测试，另有独立双季会话、源题索引、防止演示题被计数与状态标志晋级的反例，以及两季所有完整答案组合的**程序化穷举**（第一季 4^8=65,536；第二季 2^6=64）。这只能证明实现对**本站定义的演示规则**保持一致；代码和预期值同源时仍可能同时出错，需要独立金标准。
- 运行 `npm run audit:reproduction`：核查公开观察数量与本站演示数量，并始终如实显示节目原版等价状态未证实。
- 运行 `npm run check && npm run build`：Astro 类型/构建可用性；需要在真实桌面浏览器和 iPhone 18 Pro Max 440×956 CSS px 验收中文、双语顺序、结果、错误与回退路径。
- 人工/第三方审校仍不可省略：双语语义、原始证据、重用许可、节目规则与嘉宾公开账号归属。测试通过**不自动把这四个 UNKNOWN 变成 PASS**。

## 宣称「忠实复刻」之前的发布闸门

两季分别确认：合法可用的逐题韩文与选项完整、独立中文双语复核、完整答题状态图覆盖、可靠的官方评分规格或金标准差分通过、嘉宾可比数据真实、隐私和移动端验收通过，方可在对应范围内使用「复刻」措辞。否则只发布「独立创作演示版」，公开缺口。
