## 首要验收合同：官网答卷的中文等价实现

现行唯一产品愿望见 [WISH.md「北极星」](../WISH.md)：**不懂韩语的人在这里读懂同一套题，并在选择完全相同的选项后获得与官方完全相同的结果。** 本文只负责证据与过门，不再另立一个可降低的产品目标。

**一份合格的同输入→同输出金标准**必须同时具备：

1. **相同测试版本**：季别、官方 `questionnaireVersion`、`questionSetHash`、`scoringVersion`，并记录源客户端完整资源 SHA-256；服务端 `questionSetHash` 只按其实际 16 位短字符串保存，不冒充完整 SHA-256。
2. **相同实际输入**：提交前已逐题核验的完整 `{官方 sourceQuestionId → 原始选项值}` 映射，含全部适用问题、顺序／跳题条件、修改后的最终值。**主观打算全选 X、结果截图、仅有结果 ID，均不能补充或取代输入验收。** 本站中文选项显示不得改变该映射。
3. **官方可复核输出**：同一次提交的公开结果读回及证据时点；对齐所有当前可见官方结果字段（各轴方向、`leftPercent/rightPercent`、强度／离散档、`resultType`，第一季适用的结果代码及其定义），中文结果说明须独立审校其语义。
4. **本地确定性差分**：使用与同版官方输入完全一致的源题值，在本站**独立计算**并逐字段比对，任何单值不一致均判失败；若官方定义存在显示舍入／并列规则，必须先取得证据，不能自定模糊容差。原始输入、版本及比较报告相互可追溯；非合成真人答卷不得存入公开仓库。

## 四层验证，必须逐层过门

### L1 · 内容完整性：全部题目到底有没有

1. 对每一季建立**有编号的权威来源清单**；逐题记录韩文题干、全部韩文选项、选项数量、答题类型、原站顺序、截图/网页位置、抓取核实日期、重用权限与源版本。
2. 只在合法许可下保存、公开原题；权限不明时只记录题号、题型、元数据和出处链接。禁止用模型脑补补齐缺失题目。
3. 交叉核对题数、题号是否连续或明示的非连续编号、重复、缺项、隐藏条件题、原版是否更新。公开页面数量一致**只是必要条件，不是充分条件**。
4. 每道发布题强制「韩文原文在前、中文译文在后」，题干、所有选项和量表都需独立双语审校；否定、条件、程度词与计分极性不能漂移。复核详见 [翻译标准](TRANSLATION-STANDARD.md)。

**验收输出**：两季各一份逐题证据清单和来源许可状态，覆盖率=通过审核的原题数/实际原题数。用户报告的许可覆盖当前公开材料及非营利用途，原件与授权主体未独立核验；目前完成权利核验、韩中人工复核并可标为正式译文的节目原题为 **0/124**，不能用演示题 8/87 或 6/37 表示已复刻百分比。

### L2 · 路径完整性：每个选择会把人带到哪

1. 把原站问卷建模为**有向状态图**：起点、题节点、每个可选答案的转移、返回/修改答案、条件跳题、完成节点、取消或重新开始。
2. 如果官方题数是固定的，也需检查是否存在根据先前答案改变顺序、隐藏题目或提前结束的分支，不能未经验证就假定是线性排列。
3. 为每条边留一个真实原站观察或可靠原始资料的证据；对所有可达节点做图遍历，检测死路、无法到达的题、循环与提前提交。
4. 使用模拟用户或可许可的离线样本做路径覆盖；有指数级选项组合时，先用图覆盖+边界/成对覆盖，再用精确的程序化穷举测试本站的小型演示集。

## 自动测试与人为审计的分工

- 运行 `npm test`：本站原创小型题库的题目数据、两季计分与嘉宾匹配单元测试，另有独立双季会话、源题索引、防止演示题被计数与状态标志晋级的反例，以及两季所有完整答案组合的**程序化穷举**（第一季 4^8=65,536；第二季 2^6=64）。这只能证明实现对**本站定义的演示规则**保持一致；代码和预期值同源时仍可能同时出错，需要独立金标准。
- 运行 `npm run audit:reproduction`：核查公开观察数量与本站演示数量，并始终如实显示节目原版等价状态未证实。
- 运行 `npm run check && npm run build`：Astro 类型/构建可用性；需要在真实桌面浏览器和 iPhone 18 Pro Max 440×956 CSS px 验收中文、双语顺序、结果、错误与回退路径。
- 人工/第三方审校仍是**正式翻译／原版复刻**不可省略的门槛：双语语义、原始证据、重用许可、节目规则与嘉宾公开账号归属。用户目前允许原题草稿先行试填，不等于测试通过就把上述 `UNKNOWN` 晋级成 `PASS`。

## 宣称「忠实复刻」之前的发布闸门

两季分别确认：合法可用的逐题韩文与选项完整、独立中文双语复核、完整答题状态图覆盖、可靠的官方评分规格或金标准差分通过、嘉宾可比数据真实、隐私和移动端验收通过，方可在对应范围内使用「复刻」措辞。否则只能发布明确区分的「独立创作演示版」和本次用户限定的「非官方公开原题试填／AI 初译」；两者都要公开各自缺口。
